# NIPUN — AI-Powered Competency & Learning Architecture

AI-powered competency diagnosis, adaptive learning path recommendation, diagnostic assessment evaluation, and officer capacity building platform for MoSPI (Ministry of Statistics & Programme Implementation).

## Run Locally

**Prerequisites:** Node.js v18+

1. Install dependencies:
   `npm install`
2. Set environment variables in `.env.local`
3. Run the application:
   `npm run dev`
